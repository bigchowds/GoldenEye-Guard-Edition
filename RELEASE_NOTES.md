# Runway Beta 0.1.0

First public beta of **GoldenEye: But I Am the Guard**. Play as existing Runway guards against AI Bond, transferring to another survivor when you die.

Includes Grunt, Secret Grunt and 00 Grunt; physical key collection; difficulty-specific objectives; native allied/drone combat; PP7 start and real dropped-weapon looting; AI tank driving/cannon combat; a visible hatch driver and close defence with his held gun; lethal moving-tank run-overs; one external death animation without blood; guard pain voices; and Bond stagger only in his last 15% health.

**Runway only.** Streets and Dam are planned candidates, not included maps. This public beta is internal test build v9.

Apply `GoldenEye_Im_The_Guard_Runway_v9.xdelta` directly to the clean USA big-endian `.z64` listed in PATCHING.md. No earlier patch is needed. Use 8 MB RAM and 16 Kbit EEPROM; restart the emulator and start a fresh mission rather than loading an old save state.

The download contains the xdelta, complete source patch, readable guard-mode code, rebuild instructions, validation details and credits. No game ROM or emulator save is included in the public package.

Please report the difficulty, emulator/plugin/version, settings, steps and a short clip for any beta issues. See BUG_REPORT.md and VALIDATION.md for tested behavior and remaining limits.
